# TestFlight deployment — MIANU Organizer & MIANU IT Admin

TestFlight distributes iOS builds to your team over the air: testers install
from an email invitation or a public link, and updates arrive without cables.
**TestFlight requires the paid Apple Developer Program ($99/yr).** A free
Apple ID cannot upload builds or become a tester — free-account phones use
the Xcode cable flow in [IOS_XCODE_INSTALL.md](./IOS_XCODE_INSTALL.md)
instead (and remember: on a paid team, NFC works on iOS — do **not** run the
free-mode entitlement strip from that guide).

## 0. What the repo already provides

Everything below is already configured — no changes needed to upload:

- **App icon** — `assets/icon.png` (1024×1024, no alpha, generated by
  `bash packages/build/make-icons.sh`), wired into each `app.json`. An
  app-icon-less archive is the most common App Store Connect rejection.
- **Privacy manifest** — `expo.ios.privacyManifests` in each `app.json`
  declares the required-reason APIs (UserDefaults, file timestamp, system
  boot time, disk space, active keyboard) with Apple's approved reasons, and
  Expo's pod aggregation merges the manifests that RN/expo pods ship. This
  pre-empts the ITMS-91053 warning emails after upload.
- **`ITSAppUsesNonExemptEncryption: false`** in each `infoPlist` — skips the
  export-compliance question on every upload (the apps only use HTTPS).
- **Usage strings** — NFC, when-in-use location; both set per app.
- **API URL** — baked at build time via `EXPO_PUBLIC_API_URL` in the
  `production` EAS profile (and required for the Xcode path below).
- **Versioning** — `app.json` version `0.1.0`; EAS `autoIncrement` bumps the
  build number on every production build (CFBundleVersion must differ per
  upload — that's the second most common rejection).

## 1. One-time App Store Connect setup

1. Enroll at <https://developer.apple.com/programs> ($99/yr). Wait for
   activation (usually < 24 h).
2. In **App Store Connect → Apps → +** create **two** app records:
   - Name: *MIANU Organizer* — Bundle ID: `com.mianu.organize` — SKU: `MIANUOrganization`
   - Name: *MIANU IT Admin* — Bundle ID: `com.mianu.paymentapp.admin` — SKU: `com.mianu.paymentapp.admin`
3. In **Users and Access → Integrators → App Store Connect API**, generate an
   **API key** (Admin role): note the **Issuer ID**, **Key ID**, and download
   the `.p8` file. This lets EAS upload without your password.

## 2. Build and upload — EAS path (recommended)

From each app directory:

```bash
cd apps/organizer    # then repeat from apps/admin

# one-time: let EAS generate distribution certs + provisioning profiles with
# your paid team (it will ask to log in to Apple; accept all defaults)
npx eas-cli credentials

# build the store-grade .ipa (NFC entitlements included — paid team required)
npx eas-cli build --platform ios --profile production

# upload the latest build to TestFlight
npx eas-cli submit --platform ios --latest \
  --ios-api-key-path /path/to/AuthKey_XXXXXXXXXX.p8 \
  # or, to avoid a path, set the key up once:
  #   npx eas-cli submit --platform ios --latest --non-interactive
  # after storing the key with `eas-cli submit --configure-ios`
```

Watch the build at the printed expo.dev URL; ~20–35 min each.

**Free-quota note:** EAS free builds are limited per month. `eas build
--local` (with macOS + Xcode installed) produces the identical archive
without consuming quota; add `--local` to the build command above.

## 3. Build and upload — Xcode path (no EAS)

On a Mac with the repo cloned:

```bash
pnpm install
cd apps/organizer
EXPO_PUBLIC_API_URL=https://mianu-api.karimshacker1234.workers.dev \
  npx expo prebuild --platform ios -c
pnpm ios:nfc-check -- --expect-nfc     # must print OK before continuing
```

1. Open `ios/MIANUOrganizer.xcworkspace` → target → **Signing & Capabilities**
   → tick **Automatically manage signing** → Team = your **paid** team.
   The NFC Tag Reading capability signs fine on a paid team.
2. Set the build number: target → General → **Build**: must be greater than
   any build already on TestFlight (bump by 1 each archive).
3. Device target: **Any iOS Device (arm64)** → menu **Product ▸ Archive**.
4. In the Organizer window → **Distribute App ▸ TestFlight & App Store ▸
   Upload**. First time: Xcode asks to authenticate to App Store Connect —
   sign in with the Apple ID of the paid team.
5. Repeat for `apps/admin` (`MIANUITAdmin.xcworkspace`).

## 4. TestFlight setup and testing

1. App Store Connect → your app → **TestFlight** tab. The uploaded build
   processes for 10–30 minutes (export compliance is skipped thanks to the
   plist key above; if asked anyway, answer *No* to encryption questions).
2. **Internal Testing → +** create a group, add up to 100 team members by
   email (they must be in your App Store Connect team or added as App Store
   Connect users — no Apple review needed, available in minutes).
3. Testers install **TestFlight** from the App Store, accept the email
   invite on the phone, and install the app. Updates: one tap when a new
   build lands.
4. Builds expire from TestFlight after **90 days** — upload a fresh build
   before then (for the conference: upload the week before, you're fine).
5. If external testers are needed (beyond your team, public link, up to
   10,000): the first build requires a light **Beta App Review** (~1–2 days)
   plus minimal metadata (description, feedback email).

### What to smoke-test on TestFlight builds

- Sign in with the real accounts (PINs per the README) against the deployed
  API.
- **NFC** — this is the paid-team payoff: Scan tab → hold a linked badge.
- Broadcast: head sends → organizer inbox receives → mark-read syncs.
- Hall IN/OUT at any hall, meal scan receipts, journal once-per-day.
- Presence board reflects your own device as an organizer location.

## Troubleshooting

| Symptom | Fix |
|---|---|
| **ITMS-90186 / "invalid bundle — no app icon"** | `app.json` `icon` missing or has alpha — run `bash packages/build/make-icons.sh`, rebuild |
| **ITMS-90534 / missing Info.plist property** | Re-run prebuild so `expo.json`/plist regenerate from `app.json` |
| **"The bundle identifier cannot be changed"** | The App Store Connect record and the built app disagree — use `com.mianu.organize` / `com.mianu.paymentapp.admin` exactly |
| **Build number already used** | Bump the Build (Xcode) or let EAS autoIncrement handle it |
| **"Personal development teams do not support NFC…"** | You are signing with a free team — TestFlight needs the paid team (section 0/2) |
| **Export compliance asks every upload** | Confirm `ITSAppUsesNonExemptEncryption: false` survived in the built `Info.plist` (prebuild copies it from `app.json`) |
| **ITMS-91053 missing privacy manifest / reasons** | Re-run prebuild so `PrivacyInfo.xcprivacy` regenerates from `privacyManifests`; if Apple emails about a specific API, add its category + reason to `app.json` and rebuild |
| **TestFlight build "processing" forever** | Wait 30 min; then check the email from Apple — usually a missing usage-string, which the repo already provides |
